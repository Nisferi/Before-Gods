```bash

git clone https://github.com/nisferi/before-gods.git
cd before-gods

# Открыть в Godot 4
# File → Open Project → выбрать папку before-gods
```

## Структура проекта

```
Before-Gods/
├── scenes/         # Godot-сцены (.tscn)
├── scripts/        # GDScript файлы (.gd)
├── assets/         # Изображения, шрифты, данные
├── audio/          # Музыка и звуки
├── ui/             # UI-темы и компоненты
├── shaders/        # Шейдеры (.gdshader)
├── config/         # Конфигурация игры (не секреты)
├── docs/           # Техническая документация
├── ai/             # Промпты и контекст для AI-агентов
└── tools/          # Вспомогательные инструменты
```
