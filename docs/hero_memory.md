# Механика Памяти Героя (Hero Memory System)

## Концепция

Главный герой — не обычный юнит. Он существо между мирами: смертный, несущий в себе
искру божественного. Когда герой погибает, он возрождается — но возрождение приходит
с ценой.

> *"Бог умер и забыл своё имя."*
> — вдохновение из шумерских мифов о Думузи и египетских текстов о Осирисе

---

## Разделение данных героя

Все данные героя делятся на два слоя:

### `persistent_data` — то, что выживает после смерти

```gdscript
# Сохраняется навсегда, не теряется при гибели
var hero_name: String
var total_deaths: int          # счётчик смертей (лор-элемент)
var discovered_regions: Array[String]  # карта остаётся открытой
var base_buildings: Dictionary        # постройки базы не разрушаются
var unlocked_lore: Array[String]      # найденные мифологические тексты
```

### `run_data` — то, что теряется при гибели

```gdscript
# Обнуляется при смерти героя
var hero_level: int            # возвращается к 1
var current_xp: int            # теряется полностью (или частично - см. ниже)
var learned_skills: Array[String]  # все изученные навыки забыты
var quest_memory: Dictionary   # квестовые флаги сбрасываются
var current_squad: Array[UnitData]  # отряд погибает вместе с героем (или рассеивается)
var carried_resources: Dictionary   # ресурсы при себе теряются
```

## Алгоритм гибели и возрождения

```gdscript
func hero_death_sequence() -> void:
    # 1. Зафиксировать смерть
    persistent_data.total_deaths += 1
    
    # 2. Сохранить то, что выживает
    var saved = {
        "regions": persistent_data.discovered_regions,
        "buildings": persistent_data.base_buildings,
        "lore": persistent_data.unlocked_lore,
    }
    
    # 3. Определить потери памяти (чем больше смертей - тем больше теряется)
    var memory_loss_severity: float = clamp(persistent_data.total_deaths * 0.1, 0.1, 0.9)
    var lost_keys: Array[String] = calculate_memory_loss(memory_loss_severity)
    
    # 4. Уведомить систему
    EventBus.hero_memory_lost.emit(lost_keys)
    EventBus.hero_respawned.emit({"death_count": persistent_data.total_deaths})
    
    # 5. Сбросить run_data
    reset_run_data()
    
    # 6. Показать экран памяти (нарративный момент)
    EventBus.scene_transition_requested.emit("res://scenes/ui/hero_memory_screen.tscn")
```

## Экран памяти (нарративный момент)

После гибели — не просто "Game Over". Игрок видит **экран памяти**:

- Тёмный фон, медленная музыка
- Список того, что герой **забыл** (отображается вычеркнутым)
- Список того, что герой **помнит** (светится слабым светом)
- Цитата из мифологии, связанная с темой смерти и забвения
- Кнопка: **"Пробудиться"**

---

## Нарративные последствия памяти

### Квестовая амнезия
Если герой встречает NPC, с которым уже говорил в прошлой жизни:
- NPC узнаёт героя: *"Ты снова пришёл. Ты не помнишь меня?"*
- У игрока есть выбор: признаться в амнезии или притвориться, что помнит

### Карта и terrain
- Карта **не сбрасывается** (persistent) — мир остаётся открытым
- Но некоторые ноды могут "потемнеть" (эффект тумана возвращается)

### База
- Постройки **не разрушаются** — они остаются, как древние руины,
  которые герой находит и узнаёт подсознательно

## Прогрессия через смерти

Каждая смерть — не провал, а часть истории:

| Смерть # | Новый элемент |
|----------|---------------|
| 1 | Первое осознание: герой видит тень своего прошлого "я" |
| 3 | Открывается скрытый диалог с мистическим существом |
| 5 | Разблокируется особая способность (память прошлых жизней) |
| 7 | Финальное откровение о природе героя |
